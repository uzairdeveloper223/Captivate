# Captivate 0.1.0

The first public release of Captivate, a Linux desktop utility for customizable Wi-Fi captive portals.

## Features

- Configure a Wi-Fi hotspot from a Python/PySide6 desktop application.
- Host welcome, terms-of-access, and reusable voucher pages, or a custom static website.
- Preview portal pages locally before starting the hotspot.
- Host pages offline or share a separate IPv4 uplink after visitor confirmation.
- Configure timed access, inspect connected-client leases, and view session logs.
- Authorize networking through PolicyKit and recover interrupted sessions.
- Use the selected uplink's DNS servers and clean up stale Captivate DHCP/DNS services before startup.

## Installation

Binary packages require **x86_64, glibc 2.39+, and a NetworkManager-based desktop**. The build target is Ubuntu 24.04; Debian 13+ is a compatible packaging target requiring independent runtime testing. The Wi-Fi adapter must support AP mode, and internet sharing requires a separate connected uplink.

For Debian or Ubuntu:

```bash
sudo apt install ./captivate_0.1.0_amd64.deb
captivate
```

For the AppImage on Debian or Ubuntu:

```bash
sudo apt install network-manager dnsmasq-base nftables pkexec iproute2 iw
chmod +x Captivate-0.1.0-x86_64.AppImage
./Captivate-0.1.0-x86_64.AppImage
```

If FUSE is unavailable:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./Captivate-0.1.0-x86_64.AppImage
```

Run Captivate as a normal desktop user. It requests administrator authorization when starting or recovering a hotspot. If a visitor's sign-in prompt does not appear, open `http://10.42.0.1/` or the configured gateway address.

Verify downloaded files with `SHA256SUMS` in the same directory:

```bash
sha256sum --check --ignore-missing SHA256SUMS
```

## Compatibility and scope

Captive sign-in notifications depend on the visitor's operating system. HTTPS is not intercepted, offline hosting does not provide internet, and existing firewall/VPN policies may affect sharing. Vouchers are manually issued and reusable; automated payment verification is outside this release.

Source installations require Python 3.11+.
